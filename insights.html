AI Analyst — configuration

Ollama (recommended): free and 100% on-device. Install from ollama.com, then run ollama pull llama3.2. For the browser to reach it, start it with CORS open: OLLAMA_ORIGINS="*" ollama serve (Mac: run launchctl setenv OLLAMA_ORIGINS "*" once, then restart Ollama).
Hosted fallback: any OpenAI-compatible endpoint works — e.g. Groq (free tier) with URL https://api.groq.com/openai and model llama-3.1-8b-instant.
